# MyRasa SmartMart – KPI Dashboard (Demo)

Live dashboard: https://shab-analytics.github.io/myrasa-kpi-dashboard/

A demo of the KPI framework from my MyRasa SmartMart case study (OPMM6013 Strategic Marketing, MBA, Universiti Utara Malaysia).

It shows how management would decide whether to scale the smart retail pilot at the month-9 review:
- **Decision gate:** green / amber / red, based on agreed rules
- **Six KPIs:** task completion, checkout time, customer effort, service recovery, 90-day repeat purchase, contribution per outlet
- **Pilot vs matched comparison stores:** trend charts with a shaded baseline period
- **Four guardrails:** system availability, price accuracy, privacy complaints, staffed-lane cover

⚠️ All figures are hypothetical, invented to show how the framework would be used. They are not case findings.
